# 冷戰・地下檔案 — Godot 原型 v0.1

適用：香港中六歷史科溫習。Godot 4.7.2、GDScript、2D 像素風、手機／平板橫向、100 題。

## 開始試玩

1. 開啟 Godot，在專案管理員選「匯入」。
2. 選擇本資料夾內的 `project.godot`，匯入並開啟。
3. 按 F5 執行。第一次開啟需要等待字型及圖示匯入。
4. 在主頁選「全部冷戰內容」或指定主題，再按「進入迷宮」。

網頁版位於旁邊的 `ColdWarMaze-Web` 資料夾。本次已在本機開啟測試網址 http://127.0.0.1:8765/ 。該網址只適用於這部電腦，且需要測試伺服器保持執行；不是已公開的學生網址。若伺服器已停止，可在網頁資料夾執行 `python preview.py`，然後開啟同一網址。

Godot 網頁版必須透過 HTTP/HTTPS 伺服器載入，不能直接雙擊 `index.html`。正式部署時需把網頁資料夾內的 HTML、JS、WASM、PCK 及圖示一併上載至支援 HTTPS、WebAssembly 和正確 MIME 類型的靜態網站主機。正式上線及 iPhone／iPad 實機驗證尚未完成。

## 已實作玩法

- 每局重新生成 21 × 13 格迷宮；收集三份文件，再走到出口。
- 沒有倒數、生命值或敵人追逐。約 5–15 分鐘是設計目標，實際時間視答題及尋路速度而定，尚待學生試玩校準。
- 觸控方向鍵，或 WASD／方向鍵移動；走到文件格會自動拾取。
- E、空白鍵或右側「調查」按鈕，挑戰當前格或相鄰物件。走向上鎖的門亦會觸發問題。
- 普通門答對後本局保持開啟。答錯先顯示答案和解說，按繼續後抽另一題，直到答對。
- 寶箱、瞭望塔及捷徑各有一次機會；答錯後該物件本局鎖定，不再出新題。
- 寶箱答對獲得 3 枚金幣。金幣只買探照燈，沒有其他用途。
- 瞭望塔只標示最近最多兩個尚未開啟、未標示的寶箱，不揭開道路或標示出口。若無剩餘寶箱便沒有新標示。
- 捷徑連接迷宮內的兩段路，不直接接到出口。所有獎勵失敗時，原有普通道路仍可完成任務。
- 離開照明範圍後，迷霧立即重新覆蓋。已開門不會重設；被瞭望塔標示的寶箱位置會保留至開啟或鎖定。

## 音樂與音效

首頁沿用探索配樂；答題及商店降低音樂音量。暫停、切到其他應用程式或關閉音樂時會靜音。首頁與暫停選單可獨立切換音樂、音效。

移動、碰牆／鎖門、調查、答題操作、收齊文件、金幣不足、進入商店及漏答均有提示音。頻繁音效設有播放間隔；切換燈與方向按鈕不疊加普通點擊聲。漏答及金幣不足的按鈕可按來取得提示，但不會提交答案或購買裝備。

背景音樂使用獨立 Stream 播放器，短音效使用另外的播放器。新增合成音效可用 `tools/generate_audio.py` 加音效名稱重新生成；已確認項目見 `AUDIO_TODO.md`。

| 裝備 | 費用 | 功能 |
|---|---:|---|
| 基本照明 | 免費 | 附近小範圍照明，足以完成任務 |
| 廣角燈 | 3 金幣 | 附近較大範圍，牆壁仍會擋光 |
| 雙向探照燈 | 6 金幣 | 保留基本照明，沿面向的前後兩方向直照通道盡頭，無距離上限；保留三格光帶寬度，不額外向左右延伸、不拐彎、不穿牆或未開門 |

本局買入後不會耗盡，可以用「切換燈」或 L 鍵切換；新一局重新由基本照明開始。價格、照明範圍和寶箱金幣數是本原型的初始平衡值，待試玩後可調整。

## 題庫與學習紀錄

- `data/questions.json` 是遊戲實際讀取的 100 題，題號對應教師審閱版 v2。
- 題型：40 MC、16 排序、16 配對、14 分類、14 找錯。
- 選項及卡片次序會打亂，答案以內部索引判分；畫面上的解說顯示實際文字，不會引用已打亂的 A/B/C 選項字母。
- 配對及分類須全部完成後提交；找錯須同時選中錯誤片段及正確替代文字。
- 全範圍模式先抽主題，再按未見／答錯／答對紀錄加權抽題。近期同題及同組知識點會優先避開。主題題數少時會適度重複。
- 答題表現存在目前瀏覽器的 localStorage。Godot 原生版則存於 `user://study_v1.json`。兩者互不共享。
- 不用帳戶、沒有雲端同步、沒有 AI API、沒有學生姓名及教師後台。清除瀏覽器資料、更換瀏覽器或更換網站來源可能失去或看不到紀錄。
- 只保存學習表現，不保存本局迷宮進度；重新整理網頁或離開本局會開始新局。
- 第 62、64 題依教師指定按「筆記記載」判分，保留限定題幹，不把此口徑改寫成一般史實題。

## 專案檔案

| 檔案 | 用途 |
|---|---|
| `scripts/game.gd` | 畫面、操作、答題介面、道具及任務流程 |
| `scripts/maze.gd` | 隨機地圖、路徑、門及照明遮擋 |
| `scripts/study.gd` | 抽題、判分及本機學習紀錄 |
| `data/questions.json` | 可編輯的題庫資料 |
| `tests/test_game.gd` | 地圖與題庫核心測試 |
| `tests/test_flow.gd` | 獎勵、道具、換題及完整過關測試 |
| `export_presets.cfg` | 單執行緒 Web 匯出設定 |

在 Godot 安裝相符的 4.7.2 匯出模板後，可用「專案 → 匯出 → Web」更新網頁版。匯出位置預設為相鄰的 `ColdWarMaze-Web/index.html`。本機構建使用工作資料夾中的獨立 Godot 副本及模板，沒有修改你的現有 Godot 設定。

## 驗證

本次已完成：

- 250 個隨機種子的保底路線測試：三份文件與出口都可達，所需路線共有 11–13 扇普通門。
- 100 題正確／錯誤答案判分、320 次主題抽題，以及避免立即重抽同題。

- 寶箱獎勵、燈具價格與重複裝備、瞭望塔只標示寶箱、獎勵答錯鎖定、普通門答錯換題，以及全獎勵失敗後過關。

這些是原型驗證，不代表已完成所有裝置相容性或課堂效果測試。iOS Safari 實機、多人課堂網絡載入速度及 5–15 分鐘節奏仍需試玩。

## 美術與字型

遊戲圖示以提供的參考圖重新構圖，主圖為 `assets/icon.png`，Windows 圖示為 `assets/icon.ico`。網站分頁、Apple 主畫面及網頁 App 圖示位於 `web/`；自動部署會一併複製。手動從 Godot 匯出網站時，亦須把 `web/` 的內容複製到匯出資料夾，或使用 `tools/export_web.ps1 -Godot <Godot執行檔路徑>`。修改圖示來源後可執行 `tools/build_icons.ps1` 重建各尺寸。已加入主畫面的裝置可能需要重新加入，才會更新系統快取的圖示。

像素人物、牆壁、寶箱及地圖物件由專案程式繪製，沒有外部美術依賴。字型 `ArchiveStudySans.otf` 是 Noto Sans CJK TC 的字元子集，使用 SIL Open Font License 1.1，授權條款位於 `assets/FONT_LICENSE.txt`。子集包含現有題庫與介面使用的字元；新增題庫若出現缺字，需更新字型子集或換回完整的開源繁中字型。
